# 手工织锦纹样排版台

直接打开 `index.html` 使用，无需构建或服务端。数据保存在浏览器 localStorage。

## 功能

- 网格绘制：新建 6–36 列 × 6–32 行画布，8 色线，单点/十字/小菱形纹样块，按住拖动连续填色。
- 用色统计：每色格数、重复单元预览、按行换色密度给出断线风险提示。
- 撤销 / 重做（最多 50 步，刷新后仍保留）。
- 本地保存方案；导出 / 导入 JSON。
- **多版本协作审改**：
  - 把当前纹样存为命名版本（含时间、尺寸、缩略图）。
  - 从任意版本「从此版绘制」继续修改（自动记入撤销栈，可退回）。
  - 任选两个版本查看：逐格差异（红框）、每色数量 B−A 变化条形图、四连通受影响区域（点击区域在两版与合并网格上高亮）。
  - 逐格处理冲突：虚线格点击在 A/B 之间取舍，支持全部取 A / 全部取 B / 交换 A/B；未完成的逐格选择刷新后保留，导出工作区时也会随文件带走，在别处导入即可接着审改。
  - 完成合并后：合并结果载入画布，用色统计、断线风险、撤销记录同步更新，并在合并记录中留档（含冲突数、取 A/取 B 数）。
  - 合并记录可再次载入继续绘制、转存为命名版本或删除。
  - 所有版本、合并记录、进行中的冲突选择均持久化，刷新页面不丢失。
- **导出工作区**：导出含当前画布、全部版本与合并记录的 JSON；用「导入还原」可在另一台机器完整恢复。旧版单图案 JSON 仍可导入（仅还原画布）。

## 数据键

- `zfl31Pattern` 当前画布
- `zfl31PatternHistory` 撤销/重做栈
- `zfl31PatternVersions` 命名版本
- `zfl31PatternMerges` 合并记录
- `zfl31PatternMergeSession` 进行中的合并冲突选择

导出的工作区文件带 `format: "zfl31-brocade-workspace"` 标记，版本号 `version: 2`。
